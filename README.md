# Advanced Drawing Tool (एडवांस्ड ड्रॉइंग टूल)

A feature-rich drawing / painting web app with a Hindi (Devanagari) UI — draw, sketch and create artwork directly in the browser. Single self-contained HTML file: no build step, no backend, no dependencies to install.

## Features

- Full canvas drawing surface with brush tools
- Hindi-language interface with icon toolbar (Font Awesome)
- Color picker, brush sizes, shapes and styling controls
- Undo/clear and artwork export (save your canvas as an image)
- Fully client-side — works offline after first load

## Tech stack

- HTML5 `<canvas>` API
- Vanilla JavaScript (single file)
- Font Awesome icons via CDN

## Quick start

No install, no build:

```bash
open index.html
```

Or open it from any static web server / hosting provider.
